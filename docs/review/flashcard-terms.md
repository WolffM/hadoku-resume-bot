# Flashcard term review — skills section + load-bearing resume terms

Review checklist for interview-prep flashcards. Every technical term the resume displays,
verified against actual code under `/home/hadoku/repos/` (2026-08-12).

**How to read "Verified usage":**

- Repo names = real, tracked code found (`git grep` / tracked-file evidence, lock files and vendored code excluded).
- `WORK ONLY` = the claim lives at Microsoft/Charles River; no personal-repo evidence is _expected_, but you must still be able to speak to it cold.
- `NOT FOUND IN REPOS` = no genuine usage anywhere, including work-claim context being thin — drop the term or brush up hard.
- Forks of third-party code (torchsparse, sparsehash-c11, hi3dgen, d3ds2, stdgen) are noted as "(fork)" — weaker evidence than owned repos.
- `Web_of_Dreamers` is an Obsidian vault containing old resume drafts; hits there were **excluded** as evidence throughout.

Probe likelihood: HIGH = interviewer will likely dig in; MEDIUM = plausible follow-up; LOW = background tooling nobody probes.
